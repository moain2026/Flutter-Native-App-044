## المصادقة (بالبريد الإلكتروني)
| التدفق | الخطوات |
|---|---|
| تسجيل الدخول | **البريد** → موجود؟ نعم: كلمة المرور → **رمز 6 أرقام يُرسل إلى البريد** → دخول · لا: ينتقل تلقائياً إلى إنشاء حساب بالبريد نفسه |
| إنشاء حساب | البيانات (Form + Validation) + اختيار الدور → رمز إلى البريد → **الحساب يُنشأ بعد التحقق فقط** |
| نسيت كلمة المرور | البريد → رمز إلى البريد → مطابق؟ نعم: كلمة مرور جديدة (UPDATE فعلي) · لا: رسالة فشل |
| بلا SMTP في البناء | الرمز يُعرض داخل التطبيق مع زر نسخ (وضع المعاينة) — التدفق لا يتعطل |

الرمز صالح 10 دقائق، 5 محاولات، إعادة إرسال بعد 45 ث، يبقى صالحاً بعد الخروج لتطبيق البريد والعودة. رمز الدخول قابل للإيقاف من الإعدادات.

## الأدوار
- **زبون**: تصفح، بحث/تصفية/ترتيب، تفاصيل ومراجعات، مفضلة، سلة بكوبونات (`YECO10` / `WELCOME` / `BIG25`)، إتمام الطلب، تتبع/إلغاء الطلبات، حسابي.
- **بائع**: كل ما سبق + لوحة إحصاءات، **إضافة/تعديل/حذف المنتجات** (صورة من المعرض/الكاميرا)، إدارة كل الطلبات وتغيير حالتها.
- **اسم المطوّر واسم المتجر** قابلان للتعديل من داخل التطبيق (الإعدادات) ويظهران في "حول".
