## ما الجديد (كل شيء — الإصدار الأول)

### 1) المتجر
- 6 تصنيفات: الأثاث، المواد الغذائية، الإلكترونيات، الملابس، المنزل والمطبخ، الرياضة — كل تصنيف بلون وأيقونة وصورة.
- 24 منتجاً واقعياً (اسم، ماركة، وصف تفصيلي، سعر، سعر قبل الخصم، مخزون، تقييم، عدد المقيّمين، مميز).
- الرئيسية: ترحيب بالاسم والمدينة، بحث، بانر كوبون، شريط تصنيفات أفقي، "منتجات مميزة"، "عروض وخصومات"، "وصل حديثاً" (شبكة 2×2).
- قائمة المنتجات: بحث حي، Chips للتصنيف و"المتوفر فقط"، 5 أنواع ترتيب، تبديل شبكة/قائمة، عدّاد النتائج.
- التفاصيل: SliverAppBar بصورة Hero، شارات (تصنيف/ماركة/مميز/مخزون)، سعر وخصم، وصف، مواصفات، مراجعات (إضافة/تعديل/حذف مراجعتي) تُحدّث تقييم المنتج، Stepper كمية، "أضف" و"اشترِ الآن" (ينتقل إلى تبويب السلة).

### 2) السلة والطلبات
- UPSERT يجمع الكميات، +/− مع حدّ المخزون، حذف بالسحب مع تأكيد، تفريغ السلة.
- كوبونات: `YECO10` (10%)، `WELCOME` (15% فوق 100)، `BIG25` (25% فوق 500). توصيل 25 ر.س ومجاني فوق 300.
- إتمام الطلب: Form (جوال/عنوان) + RadioGroup للدفع + ملخص → حوار تأكيد → transaction (إدراج الطلب والبنود، خصم المخزون، تفريغ السلة) → صفحة الطلب.
- الطلبات: تصفية بالحالة (5 حالات)، بطاقة بصور المنتجات والإجمالي، تفاصيل بخط زمني وفاتورة وبيانات توصيل، إلغاء (يُعيد المخزون) للطلبات قيد المراجعة/المؤكدة.

### 3) البائع
- التسجيل بدور "بائع" يبدّل التبويب الرابع من "المفضلة" إلى "متجري".
- لوحة: الإيرادات، الطلبات، قيد المراجعة، المنتجات، نفدت الكمية، الزبائن + الأكثر مبيعاً + توزيع التصنيفات (LinearProgressIndicator).
- إدارة المنتجات: بحث، تصفية، مخزون منخفض، تمييز ★، تعديل، حذف بالسحب، FAB للإضافة.
- نموذج المنتج: تحقق كامل (اسم ≥3، ماركة، سعر >0، قبل الخصم > السعر، كمية ≥0، وصف ≥10)، صورة من المعرض/الكاميرا (تُنسخ إلى مجلد التطبيق) أو صورة التصنيف.
- إدارة الطلبات: تغيير الحالة بـ ChoiceChips (الإلغاء يُعيد المخزون)، حذف الطلب.
- أزرار تعديل/حذف في أعلى صفحة تفاصيل أي منتج.

### 4) المصادقة بالبريد
- **الدخول بثلاث مراحل**: البريد → (موجود) كلمة المرور → رمز إلى البريد → Shell. (غير موجود) → صفحة إنشاء الحساب بالبريد مُعبّأ.
- **إنشاء حساب**: SegmentedButton للدور، 6 حقول بتحقق فوري، موافقة على الشروط → رمز → الحساب يُنشأ ويدخل مباشرة.
- **نسيت كلمة المرور**: 3 خطوات بمؤشر StepDots؛ الرمز الخاطئ يعرض "غير مطابق" مع عدد المحاولات.
- **OtpPanel**: عدّاد 10:00، محاولات 5/5، لصق من الحافظة، إعادة إرسال بعد 45 ث، وعند تعذّر الإرسال: الرمز داخل التطبيق مع زر نسخ.
- بريد HTML عربي RTL بهوية YECO، الرمز في العنوان والجسم في خانات مستقلة.
- `KeyboardResumeFix`: تظهر لوحة المفاتيح بعد العودة من تطبيق البريد.

### 5) الحساب والإعدادات
- حسابي: رأس بتدرج لوني، الدور والمدينة، طلباتي/إدارة الطلبات، تعديل البيانات، تغيير كلمة المرور، الإعدادات، حول، خروج، حذف الحساب.
- الإعدادات: التحقق بخطوتين (Switch)، **اسم المتجر** و**اسم المطوّر** (Dialog تعديل → SQLite `app_settings`).
- حول: الإصدار، المطوّر (من الإعدادات)، المقرر، المنصة، المزايا، التقنيات.

### 6) الترخيص عن بُعد
كما المشاريع السابقة تماماً: `license.json` → `active:true` دخول / `false` كود / 404 قفل نهائي / بلا إنترنت آخر حالة. GitHub Contents API أولاً ثم raw. مُختبَر بـ 6 اختبارات.
